# Sankalp Android App

Features in this starter build:
- Daily Sankalp text
- Mantra tap counter: 108 / 1001
- Audio, video and image import/delete sections
- In-app web browser / Google
- Settings
- Double-back exit behavior
- Android Studio project structure

Build:
1. Open this folder in Android Studio.
2. Let Gradle sync.
3. Build > Build APK(s).
4. APK is normally generated under app/build/outputs/apk/debug/app-debug.apk

Note:
This is a functional starter/MVP. For a production release, persistent media metadata/database, background audio, downloads manager, richer playback controls, presets, and voice commands should be added.
